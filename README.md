# PINKHOUSE Backend

## Run

```bash
npm install
npm start
```

Server: `http://localhost:3000`

## Main pages

- Setup: `http://localhost:3000/nh_p_th_ng_tin_thi_t_b/code.html`
- Dashboard: `http://localhost:3000/b_ng_i_u_khi_n_d_o_n_1/code.html`

## APIs

- `GET /api/health`
- `GET /api/setup`
- `POST /api/setup`
- `GET /api/dashboard`
